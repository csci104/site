⚡ Modular Exponentiation

Step-by-step trace: computing b^n mod m

C++ Algorithm

// N = bits of n in LSB-first order
int modExp(vector<bool> N, int b, int m) {
int x = 1, r = b % m;
for (int i = 0; i < N.size(); i++) {
if (N[i] == true)
x = (x * r) % m;
r = (r * r) % m;
}
return x;
}
